关于“我想写博客想了四年”这档事

两年前的秋天，我在札幌街头紧紧抱住了自己。第二天上午，从酒店退房后，我在大堂的咖啡厅里坐下，一边哭，一边写下了时隔两年的一篇博文草稿。然而，那篇博文最终却没有被发布，我被莫名的恐惧与工作的琐碎缠住，直到今天……

“神圣”的写作？真实与美的表达，冲突与顾虑

坐下来写作，无论是用纸笔还是用电脑，从某个时候开始，让我觉得不可想象。

最难的是开篇。脑子里常常浮现出想法与词句，但在我真的坐下的之时，缤纷的思考瞬间烟消云散，我望着空白的荧幕，又或是纸张，郁闷地想，“人为什么不能直接把大脑的思考印出来？”不过，一旦开始试着写下零碎的、和初构题相关的片段，想法便会一个接一个蹦出来，疯狂地长出来，快到超过手指的速度。若此时我是用笔在写，大概三十分钟后页面上的字迹就会变得凌乱不堪，或许一小时后我会因感到停不下来而苦恼，抑或被激发痛苦而开始哭泣，却无法停下。

那天也是这样的。我记得我在 Fedi 高兴地宣告：“我要发博客了！”有善良的朋友回应说太好了，结果是最后什么都没发，现在想来还是有些惭愧。

原因？在准备 publish 前，我重新阅读了草稿。我感到愕然、羞耻，我心想，“这不能发！”到底写了什么（笑）？简单来说，某天，我在札幌几乎无人的某个人行横道等待交通灯时，突然崩溃了，于是我试图想象一些东西来让自己平复下来，我的想象生效了，我恢复了冷静，我冷静地穿过人行横道，冷静下来的心狂热地想要分享这份救赎感，于是我写了，但是当我准备发布时，我才发现我的想象不是我能够承受之愿意公开分享的内容。

但我依旧想要发博文。于是过了一阵子，我尝试以那份草稿为蓝本，重写一篇我认为可以公开的文章。

唉，结果我更加写不下去了！

我感到到自己在试图用华丽的辞藻、像是有仪式感一样的结构，去修饰那如履薄冰、不敢暴露脆弱的思绪。意识到的时候，我自己和我的文字，突然变得虚伪无比。呵，我觉得素然无味、无趣至极。我无力也无心完成第二份草稿了。

自那之后，写作，尤其是写博客，对我来说变得好可怕。不仅要面对拆开剖析自己内心的痛苦，以及将纷乱的思考与情感转换成能阅读的文字的耗竭感，未来的自己无力承受来自过去真诚写下文字的自己的“诚实”而想要掩饰的这份罪恶感，最让我恐惧。不真诚的写作者的文章，有去读它的价值吗？我一次又一次问自己。

于是，写作这件事就这么被我放置在了极高的位置，高到连我自己都快够不到了。“你必须要真实地表达自我，否则你的写作就会变得虚伪；你也要尽量让你的表达接近‘美’，否则你真实的呐喊对于人们来说就只是噪音。”

这四年，你去哪了？

简单概括：留学、实习、工作，正式独自在海外生存。

上面的问题，如果只是写技术博文就没什么可怕的了。但是，当你开始了社畜生涯，就会发现难得的休息日你不想做麻烦的事情了~ 折腾服务器？写作？不不不，我只想睡觉，我只想刷刷视频，玩游戏都觉得得不到休息，于是几乎只看游戏实况。或许也不全是这样，但是工作内容几乎全在舒适区之外、因性格不适合而大幅消耗心神，我愿意体谅我自己，毕竟写上一篇博文的四年前，我是无论如何都想不到内向、本科唯一挂了的科就是酒店管理学的自己会去酒店做三年的服务行业。

原因其实也很简单。

四年前在同龄人要么考公要么读研要么工作的情况下，我在毕业后选择了 Gap，不到一年时间在与父母和内心的焦虑相处之下，心理问题再度出现。同时，一些亲人也开始出现出现身体问题，我身边的人也活在焦躁之中。

两个契机让我选择了离开家，一个是玩 P4G，过程中我突然感到荒谬，心想着我在这儿操控一男高中生和游戏里的人搞好关系、尽享友谊与冒险，我为什么不去做自己这名为“人生”的游戏的主角呢？另一个是在某一天又一个失眠的夜里，我忽然强烈地感到我身边的一切都在腐朽，我的家乡、我的亲人、我自己，均在这安定却死寂沉沉的黑暗中腐朽——当我的父母老了我会如何，当我看着人们死去却什么都做不了我要如何，当我看着自己的生命逐渐凋零、再也拾不起一丝勇气时，我要如何？！

秉持反叛精神的我并未选择父母为我筛选的学校和国家，我自己找到一个专业、国家、学校，选择酒店业不过是因为它或许能让我成为 Jill，也和我本科的专业相关。很快，我以比过去想象中快得多的速度完成了必要的手续。啊，当人下了决心，做事就会变得好快，仿佛身边的一切都在助力，让我向着目标前进，别后退，不要后悔！做了想要做的事情后后悔，也比永远都不做想要做的事要好得多。

实际上，我的预感也是真的。在我抵达学校的那天，姥姥走了，家人直至一周后才告诉我。在我在另一个国家开始实习一个月后，奶奶走了。我在日本工作的第二个冬天，姥爷也走了。陪伴我童年时光不比父母短暂的老人们，在四个没有回家的春节过去后，一个都不在了。我没有见到任何一位的遗容，我在听到消息的那一刻哭，我在他们的坟墓前沉默，之后继续我的生活，然后某一次，抑或是几次，在朦胧的梦境中，我再次见到他们，普普通通地和他们交谈，而后我在异乡醒来，总要花上至少五分钟，才意识到他们真的不在了。

哈，你看老人生病后再也好不起来，在相同的医院，相似的病房，起初还能与你笑着交谈，而后一点点沉默下去，努力想要回应你的关心，却抵挡不住地昏睡过去——连流程都如此相似。好好笑，好悲哀。但我应该试着去想象他们是在我缺席的家人的祈祷中安详离开的，现在仍在天上看着我，才会偶尔托梦给我，否则一切都将那么空虚，否则生命本身仿佛不过一场幻梦。

总之，我成为了 Jill，然后，我想成为 Alma

省略我在 Fedi 吐了无数次的工作黑泥……总之，我成为了调酒师！我做了一年，经历了期待、错愕、期待落空、恐惧、强颜欢笑、卑微、绝望、重新反思人生、得到认可、获得自信，最后我潇洒（大概）离开了服务行业。

我依旧想要做调酒师，即便是决定了要转行的现在的我，也依旧认可身为调酒师的自己，也依旧喜欢鸡尾酒，在看到有趣的酒类产品忍不住多看两眼，即便暂时不喝酒了，我依旧摇晃着我的 shaker，没事调调奇怪的饮品。

从北海道，再一次独身一人，来到了东京，租下一间很小但暂时足够我生存的房间，终于有了可以不用担心被室友打扰或打扰对方的空间。

两个月的时间我沉迷于重新做学生，三点一线在住所、车站、语校间奔波，很充实，也很愉快，但无心去找工作（笑）。第三个月，除了补齐必要的行政手续并减少在日留存风险外，我突然想到，想转行 IT、口口声声说自己有建站经验，但是我这几个月连笔电都没打开，Terminal 在留学那年冬天为了修我的 Pleroma 实例（将近宕机状态持续了一个月有余）有用过之后，好像就再也没管理、折腾过服务器相关的东西了。我焦躁，但我还是打不开电脑，甚至语校也无心再去了，又想到一旦开始工作，为了适应新行业、新环境，作为新人的我根本不会有太多自己的闲暇时光。

于是我破罐子破摔了，“想做什么就趁现在做吧！”我入坑了《边狱巴士》，急速一个月打通到最新主线剧情并沉迷于刷牢。一个游戏还不够，后来怀念起小时候最爱的 Neopets 网页游戏，找了个代餐的游戏发现不对味，结果了解到 Neopets 还在运营甚至玩家还很多，又很幸运联系官方找回了多年未使用的账号，把我的小可爱们一个个喂到 bloated，心满意足寻回了好多童年的愉快。

这期间，某天想起一阵子没登录的 Fedi，一打开就看到我站的朋友约一周前发我的私讯：“外站的媒体文件好像都裂了……”

玩 084 的我已经不畏惧打开电脑，于是我时隔好久再一次打开了 Terminal。Debug，“似乎是证书的原因，不是过期的原因，似乎需要更新 Pleroma，哎呀，我好几个大版本没更新了……等等更新还需要升级系统吗？还得连续升级两次！怎么实例在运转前端却无法显示，什么当前 stable 版本 Pleroma 用的不是最新的 Pleroma-fe？那单独安装 Pleroma-fe 吧，什么 zip 文件下载不了，必须手动构建？那在本机装个 Linux 吧，好像不用虚拟机，WSL 真是好东西啊！啊修好了修好了，欸前端怎么好多 bug……是不是之前还提过其他问题，我也一起看看……”

就这样，我狂热地学语言后，狂热地玩游戏，最终又回到留学、上班前我做的事，狂热地折腾。

升级了系统后，PostgreSQL 也升级到最新，连带着搜索优化也需要重新安装。定位无法关注的群组问题，前端找到一堆 bug 后提 issues，顺带在做数据库清理时发现了后端用户删除账号的 bug，加上了提高安全性的媒体代理，开始用日志记录每一次折腾，开始 block 各种无视 robot.txt 的恶劣爬虫，安装了 Nicolium 前端，对唯一无法在本站显示媒体文件的站点排查问题并建立了临时有效方案，使用密码管理器管理密码以及配合 agent 储存使用密钥来避免密钥直接储存暴露在 Windows 文件系统中，体验了 aws 和 S3，建了个基于 Bookorbit 的“线上图书馆”（后因该服务作者的问题暂不决定开放注册而是观望），建 Vikunja 做任务清单和提醒，建 status 监控站，尽管概率很低但为了防止 hetzner 击毙我的 instance 或出问题而建立了一套定时备份到远程机器并自动监控备份是否正常运作的系统，并准备测试是否能成功基于备份文件重建实例，本地构建新的前端、在上传至服务器前确认变化，兑现我一拖再拖的建代替 funkwhale 的音乐服务器的承诺，把音乐库迁移到如今已经愈发成熟、社区超赞的 Navidrome 上，在测试了用 mounted 存储的机器上运转 Azuracast 效果不好后准备找其他合适的服务器配合 Navidrome 使用……说起来 CS 出身的朋友可能觉得这都什么小儿科的事情，这都什么基础的安全操作，早该做了，需要这么费力吗？但我的确从这个时候开始，试图用我所认为的从业者的角度，重新构建五年前（还是六年前？）自己出于兴趣、作为纯小白建立的实例，为了我自己的心灵有个能安居的地方也好，为了出了这么多问题却依然会使用我的站点的朋友用户也好，我想要让这个我的实例更长远、稳固存活下去。

Suica 还是一样菜，可时代变了

两年前的我即便想要发布那篇博文，可能也发不了。

昨天终于下定决心发博文后，在 TL 再一次爆发静态博客装修热潮的这个阶段，我实在难以忍受自己用着五年没更新的主题硬着头皮跟大家要友链……意识到重新装修博客对于现在的我的压力可能小于写作，我决定先克服一个困难。

前不久询问了 TL 业界的大家如何看待 Vide Coding，意识到在 Chat 也好 Cowork 也好，审核、手动复制粘贴代码还是效率太低了。可是，仍在补习基础 IT 知识的我，真的能保证自己做到合理使用 AI 吗，我能让 AI 直接代替我的手吗，还是说即便时代变化如此之快、快到学习使用 AI 似乎成了新时代必须要会的技能，否则就要担心被淘汰的情况下，不能等到知识储备足够的时候再去学 AI？

好在风险是有可控的空间的。我可以说除非我明白自己在做什么，否则我不会让 AI 碰我已有用户在使用的服务，全部由我亲手操作。不过，如果 AI 不安装在远程服务器呢，如果我设定严格的权限不让它看到任何当前工作环境外的数据呢，如果我用它尝试我自用的服务、甚至是静态的服务呢？

你现在看到的这个新主题，就是在这样的想法产生的两三天后诞生的。

我感到我的兴趣方向偏向后端，对于暂时没有时间学习的前端知识、本应服务于让我更舒心地写作而不是更狂热地装修的搬迁和修补博客工作，就这样成为了我的第一个常规意义上的 Vibe Coding 项目。

最新版本的 Hugo 已经不兼容五年未更新的老旧主题，但是没必要舍弃原来的自定义样式和喜欢的博客风格，直接尝试将能转移的老样式转移到新的主题上，无法兼容的部分一个个调整，再加喜欢的新样式，直至自己满意。Git action、Token、Gitalk 都失效了，那就重建、甚至可以做我想做了很久的让 Fedi 用户直接在博客下评论这种事。宽屏调整得差不多了，就调整手机显示。全程使用 WSL 支持的沙盒模式，AI 看不到我让它工作的目录外的任何东西（注意如果你是 Windows 直接安装 Claude Code 当前是无法使用沙盒模式的），而我让它看的目录，其实就是公开的博文、hugo 的结构、config 和各种样式文件。Obsidian 无法使用 WSL 下的路径作为 vault，我又不喜欢用 VS code，也不觉得后者是一个写作工作，那干脆让 AI 写个我自用的本地实时渲染 Markdown 编辑器好了——现在我就用这个它不费吹灰之力写的编辑器，以测试为借口，写下时隔两年，抑或是四年后的第一篇博文。

后记

写下这篇文章是想要告诉自己，做东西不用有压力，试着就写写当下的想法，写不下去就停。可是实际上，我想说的太多，我的思考很多，我想写的远比我想像得还多。

这个博客虽然还不完整，也不能保证所有的设备、分辨率下都能如我预期一样显示，想加的 Portfolio 还是空白的，样式可能还会更改，我也不能说我的工作流程是有效的使用 AI 工作流——天哪这是你第一次真的 Vibe Coding 不要要求这么多好吗？！

总之，好累了，但是终于做了这件困扰我、让我惦记很久的事，神清气爽了，Claude Code 额度也用尽了，过两天再折腾博客吧……虽然我用 AI 做工具，但是写作一定会一个字一个字敲打上去。

感谢看到这里的你，之后我想我们会更频繁相见！
